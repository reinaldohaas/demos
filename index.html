➕ Como Adicionar Novas Visualizações (Outras LLMs)

Para adicionar qualquer visualização gerada por Claude, ChatGPT, Gemini ou DeepSeek:

  1. Crie uma nova pasta dentro de demos/nome-da-sua-demo/.
  2. Copie o template de demos/_template/index.html ou coloque seu próprio index.html.
  3. Abra o arquivo demos.json na raiz e adicione a entrada com título, descrição e tags.
  4. Pronto! O catálogo atualizará o card automaticamente.

💡 Dica para o Git: Faça git add . && git commit -m "Nova demo" && git push para publicar automaticamente no GitHub Pages!
