Exemplo 2.3: Velocidade Instantânea e Aceleração Instantânea

Um carro de testes movendo-se ao longo do eixo x possui posição dada por x(t) = 3,0 t - 0,10 t³. Determine os equacionamentos de velocidade v(t) e aceleração a(t), a velocidade instantânea em t = 0 e o ponto de retorno (inversão de sentido).

Status: Pronto para ler
x(t) = 3,0 t - 0,10 t³
📖 Resolução Didática Passo a Passo (Fontes Amplas)
Item (A)
Derivadas para Velocidade v(t) e Aceleração a(t)
v(t) = dx/dt = 3,0 - 0,30 t²
a(t) = dv/dt = -0,60 t
📌 Passo 1: Identificação das Variáveis Disponíveis:
• Equação de posição: x(t) = 3,0 t - 0,10 t³
• Coeficiente linear: C₁ = 3,0 m/s
• Coeficiente cúbico: C₂ = 0,10 m/s³

🔹 Passo 2: Derivação de x(t) para Velocidade v(t):
v(t) = d/dt [3,0 t - 0,10 t³] = 3,0 - 0,30 t².

🔹 Passo 3: Derivação de v(t) para Aceleração a(t):
a(t) = d/dt [3,0 - 0,30 t²] = -0,60 t.

🔹 Passo 4: Avaliação Inicial em t = 0 s:
v(0) = 3,0 - 0 = 3,0 m/s; a(0) = 0 m/s².
Item (B)
Ponto de Inversão de Sentido (Parada Momentânea v = 0)
v(t) = 0 ⟹ 3,0 - 0,30 t² = 0 ⟹ t² = 10,0 ⟹ t = √10 ≈ 3,16 s
📌 Passo 1: Identificação das Variáveis Disponíveis:
• Condição de retorno: v(t) = 0 m/s
• Equação da velocidade: v(t) = 3,0 - 0,30 t²

🔹 Passo 2: Resolução do Instante de Inversão t:
0,30 t² = 3,0 ⟹ t² = 10,0 ⟹ t = 3,16 s.

🔹 Passo 3: Cálculo da Posição Máxima x_máx:
x(3,16) = 3,0(3,16) - 0,10(3,16)³ = 9,48 - 3,16 = 6,32 m (≈ 6,33 m).

🔹 Passo 4: Cálculo da Aceleração na Inversão:
a(3,16) = -0,60(3,16) = -1,90 m/s².
