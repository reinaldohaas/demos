Exemplo 2.2: Aceleração Média da Astronauta (Sears & Zemansky - Figura 2.10)

Uma astronauta em órbita realiza testes com sua unidade de manobra pessoal. Sua velocidade instantânea v_x é medida a cada intervalo de 2,0 s a partir de t = 1,0 s. Calcule a aceleração média a_{mx} = Δv_x / Δt para cada intervalo e analise o movimento.

Status: Pronto
a_{mx} = rac{v_{2x} - v_{1x}}{t_2 - t_1} = rac{\Delta v_x}{\Delta t}
📋 Tabela de Dados Medidos (Sears & Zemansky Ed. 12)
Tempo t (s)Velocidade v_x (m/s)Tempo t (s)Velocidade v_x (m/s)
1,0 s+0,8 m/s9,0 s-0,4 m/s
3,0 s+1,2 m/s11,0 s-1,0 m/s
5,0 s+1,6 m/s13,0 s-1,6 m/s
7,0 s+1,2 m/s15,0 s-0,8 m/s
📖 Resolução Didática Passo a Passo
INTERVALO (a)
t₁ = 1,0s até t₂ = 3,0s
a_{mx} = (1,2 - 0,8) / (3,0 - 1,0) = 0,4 / 2,0 = +0,2 m/s².
Velocidade e aceleração têm mesmo sinal (+): Acelera para a direita!
INTERVALO (b)
t₁ = 5,0s até t₂ = 7,0s
a_{mx} = (1,2 - 1,6) / (7,0 - 5,0) = -0,4 / 2,0 = -0,2 m/s².
Sinais opostos (v>0, a<0): Reduz a velocidade à direita!
INTERVALO (c)
t₁ = 9,0s até t₂ = 11,0s
a_{mx} = [-1,0 - (-0,4)] / (11,0 - 9,0) = -0,6 / 2,0 = -0,3 m/s².
Mesmo sinal negativo (v<0, a<0): Acelera para a esquerda!
INTERVALO (d)
t₁ = 13,0s até t₂ = 15,0s
a_{mx} = [-0,8 - (-1,6)] / (15,0 - 13,0) = +0,8 / 2,0 = +0,4 m/s².
Sinais opostos (v<0, a>0): Reduz a velocidade à esquerda!
