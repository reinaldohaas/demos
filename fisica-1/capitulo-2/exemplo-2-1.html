Exemplo 2.1: Velocidade Média e Velocidade Instantânea

Um leopardo africano está de tocaia a 20 m a leste de um jipe. No instante t = 0, ele começa a perseguir um antílope a 50 m a leste. A coordenada x do leopardo varia com o tempo conforme x(t) = 20 m + (5,0 m/s²)t². Determine o deslocamento, a velocidade média no intervalo [1,0s; 2,0s], os limites para Δt → 0 e a expressão geral para v_x(t).

x(t) = 20 m + (5,0 m/s²)t²
📖 Resolução Didática Passo a Passo (Fontes Amplas)
Item (A)
Deslocamento no Intervalo entre t₁ = 1,0 s e t₂ = 2,0 s
x(t) = 20 m + (5,0 m/s²) t²
📌 Passo 1: Identificação das Variáveis Disponíveis:
• Posição inicial da tocaia: x₀ = 20 m
• Coeficiente de aceleração: c = 5,0 m/s²
• Instante inicial: t₁ = 1,0 s
• Instante final: t₂ = 2,0 s

🔹 Passo 2: Cálculo da Posição Inicial x₁:
x₁ = 20 + 5,0(1,0)² = 20 + 5,0 = 25,0 m.

🔹 Passo 3: Cálculo da Posição Final x₂:
x₂ = 20 + 5,0(2,0)² = 20 + 20,0 = 40,0 m.

🔹 Passo 4: Cálculo do Deslocamento Δx:
Δx = x₂ - x₁ = 40,0 m - 25,0 m = 15,0 m.
Item (B)
Velocidade Média no Intervalo Δt = 1,0 s
v_méd-x = Δx / Δt = (x₂ - x₁) / (t₂ - t₁)
📌 Passo 1: Identificação das Variáveis Disponíveis:
• Deslocamento calculado no Item A: Δx = 15,0 m
• Intervalo de tempo: Δt = t₂ - t₁ = 2,0 s - 1,0 s = 1,0 s

🔹 Passo 2: Aplicação da Fórmula da Velocidade Média:
v_méd-x = 15,0 m / 1,0 s = 15,0 m/s.
(Nota didática: representa a inclinação da reta secante ao gráfico x-t ligando t = 1,0 s a t = 2,0 s).
Item (C)
Velocidade Instantânea em t₁ = 1,0 s via Limites Δt → 0
v_x = lim_{Δt → 0} (Δx / Δt)
📌 Passo 1: Identificação das Variáveis Disponíveis:
• Ponto de avaliação fixo: t₁ = 1,0 s (x₁ = 25,0 m)
• Intervalos de tempo decrescentes: Δt = 0,1 s, Δt = 0,01 s, Δt = 0,001 s

🔹 Passo 2: Avaliação para Δt = 0,1 s (t₂ = 1,1 s):
x₂ = 20 + 5,0(1,1)² = 26,05 m ⟹ Δx = 1,05 m ⟹ v_méd = 1,05 / 0,1 = 10,5 m/s.

🔹 Passo 3: Avaliação para Δt = 0,01 s (t₂ = 1,01 s):
x₂ = 20 + 5,0(1,01)² = 25,1005 m ⟹ Δx = 0,1005 m ⟹ v_méd = 10,05 m/s.

🔹 Passo 4: Avaliação para Δt = 0,001 s (t₂ = 1,001 s):
x₂ = 25,010005 m ⟹ Δx = 0,010005 m ⟹ v_méd = 10,005 m/s.

🔹 Conclusão: Conforme Δt tende a zero, a velocidade média se aproxima exatamente de 10,0 m/s.
Item (D)
Expressão Geral para a Velocidade Instantânea v_x(t)
v_x(t) = dx/dt = d/dt [20 + 5,0 t²] = (10,0 m/s²) t
📌 Passo 1: Identificação das Variáveis Disponíveis:
• Função posição: x(t) = 20 + 5,0 t²
• Instantes de avaliação solicitados: t = 1,0 s e t = 2,0 s

🔹 Passo 2: Derivação da Função Posição:
v_x(t) = dx/dt = 2 × (5,0) t¹ = (10,0 m/s²) t.

🔹 Passo 3: Cálculo da Velocidade em t = 1,0 s:
v_x(1,0) = 10,0 × 1,0 = 10,0 m/s.

🔹 Passo 4: Cálculo da Velocidade em t = 2,0 s:
v_x(2,0) = 10,0 × 2,0 = 20,0 m/s.
