Exemplo 2.1: Velocidade Média e Velocidade Instantânea

Um leopardo africano está de tocaia a 20 m a leste de um jipe. No instante t = 0, ele começa a perseguir um antílope a 50 m a leste. A coordenada x do leopardo varia com o tempo conforme x(t) = 20 m + (5,0 m/s²)t². Determine o deslocamento, a velocidade média no intervalo [1,0s; 2,0s], os limites para Δt → 0 e a expressão geral para v_x(t).

Status: Pronto
x(t) = 20 m + (5,0 m/s²)t²
📖 Resolução Didática Passo a Passo
IDENTIFICAÇÃO DE VARIÁVEIS
Variáveis Fornecidas no Enunciado:
• Posição Inicial: x_0 = 20,0 m (em t = 0 s)
• Coeficiente da Aceleração: C = 5,0 m/s²
• Equação da Posição: x(t) = 20,0 + 5,0 t²
• Posição do Antílope: x_{\text{antílope}} = 50,0 m
ITEM (a)
Deslocamento no Intervalo t₁ = 1,0 s até t₂ = 2,0 s
Δx = x(2,0) - x(1,0)
1) Para t₁ = 1,0 s: x₁ = 20,0 + 5,0(1,0)² = 25,0 m.
2) Para t₂ = 2,0 s: x₂ = 20,0 + 5,0(2,0)² = 40,0 m.
3) Deslocamento: Δx = 40,0 - 25,0 = 15,0 m.
ITEM (b)
Velocidade Média no Intervalo t₁ = 1,0 s até t₂ = 2,0 s
v_méd = Δx / Δt
v_méd = (40,0 - 25,0) / (2,0 - 1,0) = 15,0 / 1,0 = 15,0 m/s.
ITEM (c)
Tempo para o Leopardo Alcançar o Antílope (x = 50,0 m)
x(t) = 50,0 ⟹ 20,0 + 5,0 t² = 50,0
5,0 t² = 30,0 ⟹ t² = 6,0 ⟹ t = √6,0 ≈ 2,45 s.
O leopardo alcança o antílope exatamente em t = 2,45 s!
ITEM (d)
Velocidade Instantânea ao Alcançar (t = 2,45 s)
v(t) = dx/dt = 10,0 t
v(2,45) = 10,0 × 2,45 = 24,5 m/s.
📺 Alcance em t ≈ 2.45 s (x = 50.0m) | Sistema Cartesiano X-Y
