Exemplo 2.4: MRUV - Frenagem e Distância de Parada

Um automóvel viaja a v₀ = 15,0 m/s (54 km/h) quando o motorista aplica os freios com desaceleração constante a = -2,0 m/s². Determine o tempo de parada e a distância percorrida.

v² = v₀² + 2 a Δx
📖 Resolução Didática Passo a Passo (Itens a, b, c, d)
Item (A)
Tempo de Parada t_parada
v = v₀ + a t ⟹ 0 = 15,0 - 2,0 t
t = 15,0 / 2,0 = 7,50 s.
Item (B)
Distância de Parada Δx
Δx = v₀ t + ½ a t²
Δx = (15,0)(7,50) + ½(-2,0)(7,50)² = 112,5 - 56,25 = 56,25 m.
Item (C)
Verificação via Equação de Torricelli
v² = v₀² + 2 a Δx ⟹ 0 = (15,0)² + 2(-2,0)Δx
0 = 225 - 4,0 Δx ⟹ Δx = 225 / 4,0 = 56,25 m (resultado confirmado).
Item (D)
Velocidade Média Durante a Frenagem
v_méd = (v₀ + v) / 2 = 7,50 m/s
Δx = v_méd × t = 7,50 m/s × 7,50 s = 56,25 m.
