Exemplo 1.9: Uso de Vetores Unitários

Dados os dois deslocamentos A = 6 i + 3 j - 1 k e B = 4 i - 5 j + 8 k, encontre o módulo do deslocamento C = 2 A - B.

C = 2 A - B
📖 Resolução Didática Passo a Passo (Itens a, b, c...)
Item (A)
Componentes de C = 2 A - B
C_x = 2(6) - 4 = 8; C_y = 2(3) - (-5) = 11; C_z = 2(-1) - 8 = -10
Vetor C = 8 i + 11 j - 10 k.
Item (B)
Módulo do Vetor C
C = √(8² + 11² + (-10)²)
C = √(64 + 121 + 100) = √285 = 16,9 m.
